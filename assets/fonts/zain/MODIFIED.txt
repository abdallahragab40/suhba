Change (2026-11-20): the ten Arabic-Indic digits U+0660–0669 were removed
from the cmap table with fontTools; no outline or other table was changed.
Upstream Zain draws those code points with Western shapes, so the app's
Arabic-Indic digit setting had no visible effect. Without them, the digits
fall back to Amiri.

Upstream: Google Fonts distribution of https://github.com/googlefonts/zain,
version 2.000.
